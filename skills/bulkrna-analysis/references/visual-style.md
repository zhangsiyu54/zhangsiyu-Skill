# bulkRNA Visual Style

- Before final delivery, inspect PDF/PNG for overlapping labels; if labels collide, reduce label count, stagger annotations, wrap long labels, or move legends outside the panel.
- Export every figure as exactly two formats by default: PNG and PDF only.
- Background: white.
- Font: Arial, Helvetica, or default sans-serif.
- Use centered bold titles, axis title size around 21 pt, tick text around 16 pt, and keep x/y axis titles centered on their axes.
- Up genes: `#E45B5B`; down genes: `#4EA3F1`; non-significant: `#B8C2CC`.
- Use clear axis labels: `log2 fold change`, `-log10 adjusted p value`.
- Volcano plots must show threshold lines when possible.
- Heatmaps should use blue-white-red or navy-white-red scale and cluster/order samples by group.
- Put sample group annotation above heatmaps when metadata is available.
- Avoid decorative gradients, shadows, and crowded labels.
