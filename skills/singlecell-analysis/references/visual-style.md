# Single-cell Visual Style

- Before final delivery, inspect PDF/PNG for overlapping labels; if labels collide, reduce label count, stagger annotations, wrap long labels, or move legends outside the panel.
- Export every figure as exactly two formats by default: PNG and PDF only.
- Use centered bold titles, axis title size around 21 pt, tick text around 16 pt, and keep x/y axis titles centered on their axes.
- UMAP points: small, semi-opaque, no heavy outlines.
- Use stable categorical colors and preserve cluster order.
- FeaturePlot scale: light grey to saturated blue.
- DotPlot: dot size for percent expressed, color for average expression.
- Composition bar plots: stacked bars by cell type with readable legend.
- Keep legends outside crowded plot regions.
- Do not label every point. Label cluster centroids only when needed.
