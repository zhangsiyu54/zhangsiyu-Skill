# Paper Practice

Follow journal figure assembly practices: preserve data, standardize typography and color, reduce label clutter, and make panels comparable.

## Reference Sources

- ComplexHeatmap Bioconductor: https://bioconductor.org/packages/ComplexHeatmap/
- ComplexHeatmap GitHub: https://github.com/jokergoo/ComplexHeatmap
- ggplot2: https://ggplot2.tidyverse.org/
- patchwork: https://patchwork.data-imaginist.com/
- cowplot: https://wilkelab.org/cowplot/

## Paper-style Flow

1. Inventory every input figure/table and identify figure type.
2. Decide shared palette, font, panel size, legend position, and label style.
3. Preserve values, thresholds, p values, and group definitions.
4. Standardize panel labels and export every panel as PNG/PDF.
5. Write a figure manifest documenting changes and untouched scientific values.

## Visualization Pattern

- Use white background, one font family, and consistent text hierarchy.
- Move legends outside crowded panels or direct-label sparse groups.
- Align axes and plot widths across related panels.
