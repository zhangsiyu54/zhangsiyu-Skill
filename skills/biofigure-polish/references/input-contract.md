# Biofigure Polish Input Contract

Accepted inputs:
- PNG, PDF, or result tables.
- figure legend or target journal style.
- desired panel order and labels.

Preferred source:
- PNG files for default PNG/PDF polishing.
- TSV/CSV for regenerating plots.

Do not:
- alter numeric values.
- remove uncertainty or p value labels.
- relabel biological groups without user confirmation.
